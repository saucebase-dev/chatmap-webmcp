# Prototype: Landing page and sample prompts

Status: Closed
Labels: wayfinder:prototype
Assignee: Codex
Parent: ../PRD.md
Blocked by: None

## Question

What landing-page layout, copy, and sample-prompt set best explain the product
before a visitor starts their first chat?

## Comments

- The landing-page heading is "Where would you like to explore?"
- The input placeholder is "Tell me what you want to explore…"
- The landing page uses one centred column: heading, input, then three examples.
- No map or split layout appears before the first message.
- After the first message, the current split chat layout appears. Its right pane
  keeps the map blurred behind the discovery interview, then the plan review
  card. "Show my map" removes the blur and overlay.
- The landing page shows three prompts chosen at random for each new chat from
  this starting set of six:
  - Find quiet coffee shops in Shibuya for a morning of work.
  - Plan a relaxed afternoon in Lisbon with good food and a museum.
  - Show me accessible things to do near Edinburgh Castle.
  - Find a family-friendly day out in Melbourne on a low budget.
  - Help me plan a date night in Mexico City.
  - Find scenic walks and viewpoints around Cape Town.
- Each example card shows its full prompt.
- Clicking an example immediately sends it and starts the interview.
- The landing page uses the existing light and dark themes, with no separate
  illustration or background image.
- The heading and input are vertically centred, with examples just below.

- Resolution: The first screen is a map-free, vertically centred landing page
  using the existing themes. It says "Where would you like to explore?" above
  an input with the placeholder "Tell me what you want to explore…". It shows
  three full-text, clickable prompts selected for each new chat from six global
  examples. A click sends the prompt. After the first message, the existing
  split layout appears with a blurred map behind the interview or plan review
  card until the visitor reveals the map.
